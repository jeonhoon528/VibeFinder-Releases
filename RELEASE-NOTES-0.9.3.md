# VibeFinder 0.9.3 Beta

- Added automatic GitHub release checks on the first launch of each local calendar day, including published Beta releases.
- A **NEW VERSION AVAILABLE** tag appears beside the title-bar credit when a newer installer is available. Click it to open update settings.
- Customize the tag's text, background, and border in **Preferences → Colors**. Text and border default to yellow (`#FFFF00`).
- **Preferences → Updates & Community** shows the current and latest release versions, offers a manual update check, and links to GitHub Releases and Discord.
- Simplified update settings by removing the Beta checkbox, release-note box, and Preferences footer Close button.

## Installation

Run `VibeFinder-0.9.3-Beta-Setup.exe` on Windows 10/11 x64. This release provides an installer only. Installation and removal are available through Windows installed apps / Control Panel.

This Beta is unsigned. The Qt source archives accompany the installer for license compliance; `SHA256SUMS.txt` lists release asset checksums.
