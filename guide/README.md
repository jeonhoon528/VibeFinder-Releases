# VibeFinder Guide

VibeFinder Guide is a Korean and English usage assistant from JEONHOON, the VibeFinder developer. It explains workflows, controls, factory shortcuts and troubleshooting using bundled VibeFinder Help. Public plugin review is being prepared; this page is not an announcement of approval or directory availability.

## What it covers

- Library scans, search and UCS filtering, Sample lists and metadata
- Waveform playback and selection, FX Rack and Before/After/Inactive
- Send to REAPER, VibeAnalyzer, Preferences and documented dialogue tools
- Keyboard and mouse gestures, focus requirements, and version limitations

The review candidate uses a VibeFinder 0.9.8 Beta Help snapshot: 617 topic IDs and 75 factory shortcut definitions. It cannot control your running application, inspect your audio library or customized shortcuts, or process audio. Other VibeFinder versions can differ. F1 for FX Rack and F12 for Context Help are snapshot defaults; check Preferences → Shortcuts for your own assignments.

## Example questions

- “VibeFinder에서 FX Rack을 닫아도 효과가 계속 들리는 이유와 끄는 방법을 알려줘.”
- “How do I rescan only added or changed files in VibeFinder?”
- “How do I check my customized keyboard shortcuts?”

No publisher API key, purchase or payment is required by the Guide. Host-service eligibility, account limits and separate host-service terms still apply. Availability for every account or country is not guaranteed.
